# EV Monitor Dashboard

A real-time Electric Vehicle telemetry dashboard built with ESP32, Python Flask, and vanilla HTML/CSS/JS.

## Features
- Live battery %, speed, motor temperature gauges
- Voltage and current readings
- Estimated range calculator
- Color-coded alerts (normal / warning / critical)
- Works on mobile browser

## Tech Stack
- ESP32 (firmware + WiFi)
- Python Flask (backend API)
- HTML / CSS / JavaScript (dashboard UI)
- Azure IoT Hub (cloud layer - coming soon)
